# SCP-Roleplay  
*SCP Roleplay Scripting Non-offical documentation*  
Les add-ons, ajoutés à SCP:Roleplay dans sa miseè)-jour "Custom Servers Update" le 23/08/2025 ajoutent de nombreuses possibilités au jeu ainsi qu'au roleplay. Mais ce n'est pas quelque chose de forcément facile d'accès pour un totale débutant. De plus, la documentation officiel n'est pas des plus clairs. C'est pour ça que ce document existe : Il améliore l'améliorable.
